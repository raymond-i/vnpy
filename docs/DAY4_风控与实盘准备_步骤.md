# Day 4：风控、实盘准备与检查清单（具体步骤）

本文为《VeighNa 入门到实盘 5 天计划书》Day 4 的可执行步骤说明，目标是在实盘前完成风控配置、日志与监控熟悉、实盘账号与配置准备，以及检查清单勾选。

---

## 目标与产出

- **目标**：了解 Trader 风控与日志，完成实盘前检查清单，并准备好实盘账号与配置（若尚未开户则完成申请与配置准备）。
- **产出**：风控配置 + 实盘（或仿真）连接参数 + 实盘前检查清单勾选完成。

---

## 前置条件

- 已完成 [Day 3](DAY3_SimNow仿真与策略实盘形态验证_步骤.md)：SimNow 下策略能完成初始化与启动。
- 计划在 Day 5 使用实盘或期货公司仿真环境。

---

## 步骤一：风险管理（RiskManager）

1. **加载模块**：若使用 [run.py](../examples/veighna_trader/run.py) 需在脚本中加入 RiskManager；若通过 VeighNa Station 启动，在配置对话框【应用模块】中勾选【RiskManager】。安装：`pip install vnpy_riskmanager`（在 .venv 下用完整路径 pip 安装）。
2. **打开界面**：Trader 菜单栏【功能】→【交易风控】。
3. **理解规则**：委托流控（时间窗口内最大委托笔数、清空间隔）、单笔委托上限、总成交上限、活动委托上限、合约撤单上限等；详见 [RiskManager](community/app/risk_manager.md)。
4. **启动风控**：在【风控运行状态】下拉框选【启动】，设置各参数后点击【保存】。之后每一笔委托都需通过风控检查才会发往柜台。
5. **实盘前建议**：实盘前务必在【交易风控】中设置合理上限并启动，避免异常或策略 bug 导致过量下单。

---

## 步骤二：日志与监控

1. **日志位置**：Trader 主界面【日志】组件；运行目录下 `.vntrader` 内也可能有日志文件（视版本而定）。
2. **日志级别**：可在【系统】→【全局配置】或 `vt_setting.json` 中调整 `log.level` 等。
3. **常见排查**：
   - 连接失败：检查服务器地址、端口、网络、账号密码与经纪商代码。
   - 合约未找到 / 行情订阅失败：确认 vt_symbol 正确、已连接接口且合约已查询到。
   - 初始化失败：确认策略文件在运行目录 `strategies` 下、无语法错误；若为 datafeed 相关，见 Day 1/2 文档。
4. 参考 [CTA策略 - 实盘运行](community/app/cta_strategy.md) 中的注意点。

---

## 步骤三：实盘账号与配置

- **若未开户**：联系期货公司开通账户及 CTP 接入，获取经纪商代码、交易/行情服务器地址、产品名称与授权编码等。
- **若已开户**：向客户经理索取实盘 CTP 连接参数（或期货公司提供的仿真环境参数）。
- **重要**：实盘与 SimNow 的经纪商代码、服务器地址不同；建议将实盘配置单独保存（如另存为配置项或文档），避免在 Trader 中误选 SimNow 导致实盘误连或反之。

---

## 步骤四：实盘前检查清单

在进入 Day 5 实盘前，建议逐项确认：

- [ ] 策略在**回测**（Day 2）和 **SimNow**（Day 3）下均已跑过，无异常。
- [ ] **vt_symbol**、合约乘数、保证金、手续费在实盘侧已确认（可与合约查询或期货公司确认）。
- [ ] **风控**已在 Trader 中配置并启动（委托流控、单笔/总上限、撤单上限等）。
- [ ] **实盘 CTP 配置**已单独保存，与 SimNow 配置区分清晰。
- [ ] 计划首日使用**小资金**或**最小手数**，便于验证流程与风控。
